## Endpoints

| Method and path | Purpose | Success |
| --- | --- | --- |
| `GET /v1/workflows` | List workflows | `200` |
| `POST /v1/workflows` | Create a custom workflow | `201` |
| `GET /v1/workflows/{workflow_id}` | Retrieve a workflow | `200` |
| `PATCH /v1/workflows/{workflow_id}` | Update a custom workflow | `200` |
| `DELETE /v1/workflows/{workflow_id}` | Archive a custom workflow | `204` |
| `POST /v1/workflows/{workflow_id}/runs` | Start a run | `200` or `202` |
| `GET /v1/workflows/{workflow_id}/runs` | List runs for one workflow | `200` |
| `GET /v1/runs` | List execution history | `200` |
| `GET /v1/runs/{run_id}` | Retrieve a run | `200` |
| `GET /v1/runs/{run_id}/results` | Retrieve results | `200` |
| `POST /v1/runs/{run_id}/cancel` | Request cancellation | `202` |
| `POST /v1/runs/{run_id}/retry` | Retry a failed run | `202` |
